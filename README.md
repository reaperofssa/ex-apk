# Better Call Saul App 🧑‍⚖️

A minimal Android app that displays Saul Goodman.

## How to build the APK (no computer needed)

1. Push this repo to GitHub
2. Go to the **Actions** tab
3. Click **Build APK** → **Run workflow**
4. Wait ~5 minutes
5. Download the APK from **Artifacts**
6. Install on your Android device (enable "Install unknown apps" first)

## What you'll see

- Dark background
- "SAUL GOODMAN — Attorney at Law"
- "Better Call Saul!"
- His famous number
- "It's all good, man."
